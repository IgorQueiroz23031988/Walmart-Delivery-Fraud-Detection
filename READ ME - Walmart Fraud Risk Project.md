Project Structure



This project is organized into four main components:



1\. Report

A comprehensive PDF document covering all stages of the analysis, including:



Business Understanding

Data Cleaning

Descriptive Statistics

Feature Engineering

Exploratory Data Analysis (EDA)

Key Findings

Fraud Risk Score Framework

Business Recommendations



2\. Presentation

A PowerPoint file summarizing the most relevant insights and outcomes of the project, including:



Business Context

Data Overview

Key Metrics

Hypotheses

Key Findings

Fraud Risk Framework

Recommendations



3\. Interactive Dashboard

A Power BI dashboard providing dynamic and interactive analysis across the main dimensions of the project:



Overview

Operational Risk

Product Risk

Customer \& Driver Risk

Fraud Risk Framework



4\. Simulator App

A web-based application that allows users to estimate fraud risk scores based on selected attributes.
